# Tutor Master

一个面向 1v1/小班教师的 Windows 端课程管理原型，使用 Python + Tkinter 编写，支持周视图课表、课程月汇总与薪资预估。

## 功能概览
- **周视图**：默认进入本周课程表，可查看每日时间轴，按年级颜色区分课程块，双击课程块即可编辑或删除。
- **月视图**：一键切换到课程月汇总，自动按照“课程月”（周一到周日，对齐自然月前后 3 天）统计周次、课时与薪资。
- **课程 CRUD**：点击“添加课程 (+)”通过表单新增课程，支持自定义时段/时长、试听标记、多人课程、备注等；周视图双击课程块可修改，按 Delete 可删除。
- **薪资计算**：内置底薪 5000、常规月/寒暑假义务课时、分年级课时费与扣减逻辑，可在月视图看到当月课时费与总额。

## 运行环境
- Windows 10/11，已安装 Python 3.10+（自带 tkinter）。
- 允许联网，但本地即可使用；数据保存在当前目录下的 `tutor_master/tutor_master.db` SQLite 文件。

## 快速开始
```bash
# 进入项目
cd tutor-master

# 启动桌面应用（确保在图形界面中运行）
python -m tutor_master.main
```

首次启动会自动创建数据库并写入 3 条示例课程，之后会复用已存在的数据文件。

## 主要约束与设计说明
- 课程时间轴从 07:00 到 22:00，支持不在默认五段内的任意时间段，也支持同一时间段多名学生。
- 年级颜色：初一/初二/初三为黄色系由浅到深，高一/高二/高三为蓝色系由浅到深。
- 课程月：按照自然月前后 3 天内、周一开始周日结束的范围自动推算；季度计算为（自然月+2）÷3 取整。
- 薪资：常规月义务课时 5 节，寒暑假（2/7/8 月）义务课时 10 节，从低年级开始扣减；课时费按 2 小时=1 课时计算（特殊时长按比例）。

## 目录结构
- `tutor_master/database.py`：SQLite 读写、课程 CRUD 与示例数据。
- `tutor_master/scheduling.py`：课程模型、颜色配置、课程月推算、周分组工具。
- `tutor_master/salary.py`：课时折算与薪资计算核心逻辑。
- `tutor_master/main.py`：Tkinter 界面，包含周/月视图切换、表单对话框、时间轴绘制。
